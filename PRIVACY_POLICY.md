# Privacy Policy for SubTrans

SubTrans is committed to protecting your privacy.

1. **Data Collection:** SubTrans does not collect, track, or share any personal identity information, browsing history, or user credentials.
2. **Local Storage:** The extension uses local storage (IndexedDB) solely to store user preferences (e.g., target language, subtitle font styles) and cache translated subtitles locally on your device for performance optimization.
3. **Network Communication:** SubTrans connects directly to translation APIs (such as Google Translate / DeepL / Gemini Cloud API) exclusively to translate video subtitles requested by the user during playback. No user information is attached to these translation queries.
4. **Optional Text-to-Speech (Vietnamese Dubbing):** The automatic Vietnamese dubbing feature is **disabled by default**. Only when the user explicitly enables it, the translated Vietnamese subtitle text is sent to Microsoft Edge Read Aloud (`speech.platform.bing.com`) solely to synthesize speech audio. No video audio, cookies, or personal identifiers are transmitted.
5. **Third-Party Services:** We do not sell or monetize user data.

For any questions, contact us via our GitHub repository.
